# 🌿 LeafNest

LeafNest is a modern and responsive flower pot and indoor plant website built using **HTML** and **Tailwind CSS**. The project features a clean, elegant interface with smooth animations, showcasing a beautiful collection of flower pots and plants. It is designed to provide a seamless browsing experience across desktops, tablets, and mobile devices.

## ✨ Features

* 🌿 Modern and responsive design
* 🪴 Beautiful flower pot and plant collection
* 🎨 Clean and user-friendly interface
* ✨ Smooth animations and hover effects
* 📱 Mobile-friendly layout
* ⚡ Fast and lightweight performance

## 🛠️ Technologies Used

* HTML5
* Tailwind CSS
* CSS Animations
